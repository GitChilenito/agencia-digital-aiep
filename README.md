# Agencia Digital AIEP - Backend JWT

Servidor de autenticación en Node.js y Express.js con JWT y cookies httpOnly.

## Estructura
- `/src/data`: Persistencia de usuarios.
- `/src/controllers`: Lógica de autenticación (login, private, logout).
- `/src/middlewares`: Validación de tokens JWT.
- `/src/routes`: Definición de endpoints.
- `server.js`: Punto de entrada del servidor.
